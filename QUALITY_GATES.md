# Quality Gates

A release is promotable only when the exact final head passes every required gate.

## v128 required gates

- locked dependency installation before parser validation;
- strict TypeScript no-emit checking for all v128 `.ts` contracts;
- parser and static syntax for inherited runtime modules, v127 UX behavior, v128 JavaScript counterparts, and the consolidated v128 bootstrap;
- browser-free v126 coordinator and v127 action-policy contracts plus v128 portable-package round-trip, canonicalization, corruption, schema, empty-vault, authority, and privacy-boundary contracts;
- Chromium, Firefox, and desktop WebKit;
- Android Chromium, iPad WebKit, and iPhone WebKit;
- keyboard and visual contracts;
- axe accessibility for retained household surfaces, action hierarchy, status feedback, runtime diagnostics, and the v127–v136 roadmap;
- unchanged Lighthouse request and byte budgets;
- public-repository security and full-history privacy/secret scanning;
- dependency review and high/critical npm audit;
- supply-chain checks and CodeQL;
- exact-head Cloudflare preview;
- unresolved review-thread check.
